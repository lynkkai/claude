# Video 1: "Wait! What did we promise them?"

50-second vertical video (1080x1920, 30 fps) with background music, built on the lynkk.ai design kit.
Script: `../video-scripts-revenue-story.md` (Video 1).

- **Final video:** `lynkk-video-1-wait.mp4` (voiceover + music). `lynkk-video-1-wait-music-only.mp4` has no voice, for recording a human voiceover later.
- **Look:** lynkk.ai tokens (night `#111` with dot grid and hairline frame, stone day sections, violet `#7063be` pill tags,
  two-tone Inter headlines, Schibsted Grotesk UI text, striped Lynkk mark, warm studio backdrop behind product shots).
- **Story:** 0-34s problem on night backgrounds, hard cut at 34s to the fix on day backgrounds, 45-50s end card styled like the lynkk.ai hero.
- **Music:** original, synthesized by `music.py` (no licensing needed). Tense minor-key pulse with a ticking clock for the problem,
  a riser into the cut, then a bright major-key groove for the fix. About -14 LUFS.
- **Voiceover:** AI voice (Kokoro TTS, open source, voice `af_heart`), generated by `voiceover.py`. Each line is timed to its scene;
  "Lynkk" is written "Link" in the spoken text so it is pronounced right. The music ducks under the voice. Final mix about -14 LUFS.

## Re-render

Needs Python 3 with numpy, Node with Playwright (Chromium), and ffmpeg.

```bash
python3 build.py                                   # inline the logo into scene.html
python3 music.py music.wav                         # background music
node render.mjs preview sheet.png 1 7 20 39 49     # optional: stills to check
node render.mjs video frames.mp4 30 50             # 1500 frames, a few minutes

# voiceover (needs: pip install kokoro-onnx soundfile, plus kokoro-v1.0.onnx and voices-v1.0.bin
# from https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0)
python3 voiceover.py kokoro-v1.0.onnx voices-v1.0.bin vo.wav af_heart

# mix: voice on top, music ducked under it, loudness -14 LUFS
ffmpeg -i frames.mp4 -i music.wav -i vo.wav -filter_complex "\
[2:a]aresample=44100,aformat=channel_layouts=stereo,highpass=f=90,acompressor=threshold=-20dB:ratio=3:attack=5:release=120:makeup=2,asplit=2[vo][sc];\
[1:a]volume=0.62[mu];[mu][sc]sidechaincompress=threshold=0.02:ratio=8:attack=15:release=350[duck];\
[duck][vo]amix=inputs=2:normalize=0:duration=first,loudnorm=I=-14:TP=-1.5:LRA=9[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 48000 -movflags +faststart lynkk-video-1-wait.mp4
```

To change a line, edit `LINES` in `voiceover.py` (start second, latest end second, text). Other voices to try: `am_michael`, `af_bella`, `am_fenrir`.

Edit copy or timing in `scene.src.html`: each scene has `data-in`/`data-out` seconds and each element a `data-t` start time.
If you move the 34s cut, move `CUT` in `music.py` too.
