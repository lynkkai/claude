How to turn on voice typing in Google Docs:
1. Open the doc in Chrome
2. Tools, then Voice typing (or Command Shift S)
3. Click the mic and talk. Say "comma", "period" and "new line" for punctuation

Google Docs voice typing not working? Check these six things:
1. Use Chrome
2. Mac microphone access for Chrome (System Settings, Privacy & Security, Microphone)
3. Chrome site access for the doc (Microphone, Allow)
4. The right input (System Settings, Sound, Input)
5. Stay in the doc, because clicking away stops it
6. Match the language above the mic, and check your connection
