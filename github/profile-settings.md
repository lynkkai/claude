## Publishing the README

GitHub shows an organization README from a public repository named **`.github`** in the org:

1. Create a public repo named `.github` under the Lynkk organization.
2. Copy `github/profile/README.md` from this repo to `profile/README.md` in that repo.
3. Commit to the default branch. It appears on the org's Overview page right away.
