# Lynkk vs Otter.ai: long video and Short

A named, factual comparison for the official Lynkk channels, requested by the Lynkk team.
Built with the `lynkk-design` skill and the kit in `lynkk-post-kit/`:

- Every Lynkk claim is from `lynkk-post-kit/docs/TRUTHS.md` (checked 2026-09-29).
- Every Otter.ai fact is from lynkk.ai/compare/otter, which cites otter.ai (October 2026). Each
  comparison board shows that source. No prices, as the kit requires.
- It shows where Otter.ai is the better pick (Windows app, file uploads, chat on every plan,
  Enterprise SSO), as `youtube/topic-research.md` asks of comparison videos.
- Screens are kit boards and mock parts; the company, people and data are fictional.
- Voice: Kokoro `am_adam` (US English male). Music: original sitar and tabla track
  (`../lynkk-vs-tools/music_indian.py`), no samples, no licensing.
