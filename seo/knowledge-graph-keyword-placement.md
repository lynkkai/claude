**Takeaway:** almost every meeting tool names this feature with a **brand word** (AskFred,
Ask Granola, Ask Fathom, Search Copilot, AI Chat) and puts it in a blog post or help article.
Nobody searches for those names unless they already use the product, so these pages rank
for nothing new. Lynkk can win just by using the generic term people actually search for.

## 2. Placement patterns: what ranks vs. what doesn't

### Doesn't rank: branded feature name in title and URL
- "Otter AI Chat: Unlocking Hidden Gems Across All Your Meetings" → ranks for nothing useful
- "Granola 2.0: A second brain for your team" → "second brain" is in the title, but the URL is
  `/two-dot-zero` and the page is a product update, so it ranks only for "granola updates"
- "Search Copilot: Revolutionizing How You Find and Use Information" → no target keyword at all

### Five title formulas that work in these SERPs

| Formula | Example | Use it for |
|---|---|---|
| `[Keyword] for [Audience] \| Brand` or `[Keyword] - Brand` | "Conversation Intelligence - Gong" | **Product/feature pages** (our knowledge graph page) |
| `What is a [Keyword]? \| Brand` | "What is a Context Graph? \| IBM" | Definition posts |
| `[Keyword]: What it is, why [X], and template` | plane.so decision log | Concept + template posts |
| `[Keyword]: Best Practices & Tools` | read.ai action item tracking | Job-to-be-done posts |
| `N Best [Keyword] in 2026` / `Best [Keyword]: N Options by Use Case` | avoma, atlasworkspace, tana | Listicles that include our product |

### Rules for the Lynkk page that follow from this
1. **Put the generic keyword first in the title tag.** No branded feature names.
2. **The URL keeps the keyword:** `/features/knowledge-graph` already does.
3. **Write the H1 as a product claim that contains the keyword.** Gong does this, and it ranks.
4. **Give each secondary keyword its own H2** so the page can rank for variants, like read.ai's
   page ranks for 12. Don't hide those keywords in body text only.
5. **Answer the definition right under the first H2** (IBM/Neo4j style). That's what
   AI Overviews and featured snippets pull from.

### Checked and skipped
- "ai meeting search", "meeting knowledge base", "search meeting recordings", "meeting recall",
  "ai meeting insights": **0 volume**. Use them in copy for clarity, not as targets.
- "knowledge graph" (9,900): definition intent, owned by Google/IBM/Wikipedia.
- "ai search tool" (1,300/25): people are looking for Perplexity-style web search, not meeting search.
- "enterprise search software" (210/39): Glean's territory, and an enterprise buyer.
- "AI memory" (2,900): mixed with chip stocks and Character AI; wrong audience.
