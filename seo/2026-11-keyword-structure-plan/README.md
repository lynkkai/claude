# Keyword plan, site structure and page changes (15 November 2026)

87 keywords across TOFU, MOFU and BOFU, chosen for being rankable at DA 2 and sending clicks.
Each keyword is mapped to one page in a 7-hub structure (6 blog hubs plus product pages).

Scoring:
- Target position from Ubersuggest SEO difficulty: SD 15 or less = #3, 16-25 = #5, 26-35 = #8, 36+ = long-term.
  Pages already in the GSC top 15 get #3.
- Projected clicks from Ubersuggest's SERP click model at the target position (with or without ads).
- P1 = easy and worth clicks (first 6 weeks), P2 = medium (weeks 6-12), P3 = long-term.

| File | What it holds |
|---|---|
| `report.html` | Top 25 keywords, structure tree, full plan by hub, homepage and product page copy changes, order of work |
| `keyword-plan.csv` | All 87 keywords with priority, hub, target page, volume, SD, funnel, current and target position, projected clicks |

None of the changes have been applied to the site.
