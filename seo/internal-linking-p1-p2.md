## How to place the links

- Put links in body prose, not in a related-posts block or a sidebar. Repeated template
  blocks start to behave like boilerplate and lose the signal.
- Use the target page's own query as anchor text where it reads naturally ("Otter.ai
  alternative", "AI notes for sales calls"), never "learn more" or a bare URL.
- One link per target per post. Repeating the same link in a post adds nothing.
- Place the first mention high in the post where possible, but do not force it.
